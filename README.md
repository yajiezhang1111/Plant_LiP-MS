# Plant_LiP-MS_PeptideTypeAnnotation
R scripts adapted for peptide type annotation using the R/Bioconductor Protti package (Quast, et al. 2022). The scripts are part of a LiP-MS protocol version adapted for plants.

Installation
Install from CRAN using the install.packages() function.

install.packages("protti", dependencies = TRUE)

or install the development version from GitHub using the devtools package

devtools::install_github("jpquast/protti", dependencies = TRUE)
